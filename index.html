Proyek Pilihan

Beberapa proyek mandiri yang saya buat untuk melatih kemampuan pemrograman, memahami kebutuhan pengguna, dan menerapkan teknologi yang dipelajari.

LocalKu

Direktori usaha lokal dengan panel admin

Rekaman layar, 3 menit 23 detik. Tonton di YouTube

Pengunjung mencari usaha di sekitar mereka berdasarkan kategori, membuka halaman detailnya, dan menulis ulasan berbintang. Admin mengelola seluruh isinya dari panel tersendiri.

  • Jelajah per kategori dan daftar bisnis unggulan
  • Halaman detail bisnis dengan rating dan form ulasan
  • Dasbor admin dengan statistik, grafik listing per kategori, dan kota teratas
  • Kelola listing, kategori, ulasan, pengguna, dan pesan masuk

Teknologi: full-stack web, database, login admin

StoKu

Kasir dan stok warung

Rekaman layar, 2 menit 20 detik. Tonton di YouTube

Dasbor kasir untuk warung: mencatat transaksi, memantau stok barang, dan membuat laporan penjualan otomatis.

  • Kasir dengan pencarian nama atau SKU dan filter kategori
  • Dasbor penjualan harian dengan tren 14 hari
  • Laporan omzet dan laba, bisa diekspor ke CSV
  • Pengaturan toko dengan pratinjau struk

Teknologi: full-stack web, database, dasbor interaktif

AIKu

Asisten AI untuk chat, data, dan berkas

Rekaman layar, 2 menit 23 detik. Tonton di YouTube

Asisten AI berbasis API yang bisa diajak mengobrol dan ditanyai soal data. Di Terminal Data, pertanyaan berbahasa Indonesia diubah menjadi query SQL ke database sampel, lalu hasilnya dijelaskan kembali.

  • Chat biasa dan mode agen
  • Terminal Data yang hanya membaca database sampel
  • Unggah berkas untuk diproses
  • Menu gambar, video, dan kode, serta dasbor pemakaian dan kuota

Teknologi: Python / Node.js, Gemini API, query kustom

TokoDo

Kasir dengan peran kasir dan admin

Rekaman layar, 3 menit 4 detik. Tonton di YouTube

Aplikasi kasir yang dipisah menurut peran. Kasir fokus melayani pembayaran tunai dan QRIS, sedangkan admin mengurus produk, pegawai, dan transaksi.

  • Login dengan hak akses kasir atau admin
  • Kasir: keranjang, uang diterima, kembalian, dan cetak struk
  • Ringkasan admin: omzet hari ini dan 7 hari, produk terlaris, stok menipis
  • Kelola produk, akun pegawai, pembatalan transaksi, dan jejak audit

Teknologi: full-stack web (PHP), pembayaran tunai dan QRIS
